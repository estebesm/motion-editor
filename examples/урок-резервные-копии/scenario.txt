# Пример: урок, написанный готовой раскадровкой (генератор берёт её как есть, без ИИ-режиссёра).
# Скопируйте папку в videos/ и запустите: ./run.sh --auto --video=урок-резервные-копии
#
# Как устроен файл (строки с одной «#» — комментарии, генератор их не читает):
#   «## Тип» — новая сцена. Типы: Текст, Картинка: <файл>, Список, Шаги, Схема, Сравнение, Важно, Финал: <логотип>.
#   Каждая строка — фраза диктора. Она же пишется на экране слово в слово, пока звучит.
#   *Слово* — выделение цветом. +слово+ — зелёным, ~слово~ — красным. **Слово** — плашкой (2–4 раза на видео).
#   [иконка] в конце строки — иконка пункта.
#   «фраза → часть фразы» — на экране только часть (те же слова в том же порядке); «фраза →» — без надписи.
#   Список / Шаги / Схема: первая строка — заголовок (у Схемы — центр), дальше — пункты по одному.
#   Сравнение: «А:» и «Б:» — две стороны, строки под ними — их пункты.
#   Картинка: <файл из sources> — скриншот, запись экрана или фото; запись экрана можно показать в рамке телефона.
#
# Без «##» в файле сценарий считается материалом: ИИ-режиссёр сам придумает сцены и текст под них.

## Текст
**Урок** первый:
что такое *резервная копия*?

## Текст
Ноутбук сломался, телефон утонул —
а вместе с ними *фотографии* и документы.
Чтобы этого не случилось, делают *резервные копии*.

## Текст
Резервная копия — это запасной экземпляр ваших файлов. → Резервная копия — *запасной* экземпляр файлов
Она хранится *отдельно* от оригинала.

## Список
Есть три вида копий: → Три вида *копий*
полная — всё целиком, → Полная [copy]
разностная — изменения с полной копии, → Разностная [layers]
инкрементная — изменения с прошлой копии. → Инкрементная [plus]

## Сравнение
А: Облако —
доступно *откуда угодно*,
но нужен *интернет*.
Б: Внешний диск —
работает *без сети*,
но его можно *потерять*.

## Шаги
Настроить копии — это *три шага*: → *Три шага*
выберите папки, → Выберите папки [folder]
задайте расписание → Задайте расписание [calendar]
и проверьте первую копию. → Проверьте копию [check]

## Схема
Правило *три-два-один*:
три копии данных, → Три копии [copy]
два разных носителя, → Два носителя [hard-drive]
одна копия — вне дома. → Одна — вне дома [map-pin]

## Важно
Копия бесполезна без *проверки*:
раз в месяц восстановите хотя бы один *файл*.

## Финал
Итог: копии — *отдельно*, по расписанию и с проверкой.
В следующем уроке — настраиваем *облако*.
